# 🐍 Curso Completo de Python - Desde Cero hasta Experto

¡Bienvenido al curso más completo de Python en español! Este curso está diseñado para llevarte desde los conceptos más básicos hasta temas avanzados, con ejemplos prácticos, ejercicios autocorregibles y una **terminal interactiva web**.

## 🌟 Características del Curso

- ✅ **16 Lecciones completas** desde introducción hasta temas avanzados
- ✅ **Terminal Web Interactiva** para ejecutar código y autocorrección en tiempo real
- ✅ **Ejercicios prácticos** en cada lección
- ✅ **Tests autocorregibles** para validar tu aprendizaje
- ✅ **Contenido nivel universitario** con ejemplos del mundo real
- ✅ **Todo en español** con explicaciones detalladas

## 🚀 Terminal Web Interactiva

¡Novedad! Ahora puedes ejecutar código Python directamente desde tu navegador con autocorrección automática:

```bash
# Iniciar la terminal web
python web_interfaz/server.py
```

Luego abre tu navegador en: **http://localhost:8000**

La interfaz web incluye:
- Editor de código integrado
- Ejecución inmediata de código
- Autocorrección de ejercicios
- Seguimiento de progreso
- Retroalimentación instantánea

## 📚 Estructura del Curso

### **Nivel Básico**

3. **[Lección 03: Operadores](leccion03-operadores/)** - Aritméticos, comparación, lógicos y de asignación
4. **[Lección 04: Estructuras de Control](leccion04-estructuras-control/)** - Condicionales (if/else) y bucles (for/while)

### **Nivel Intermedio**
5. **[Lección 05: Funciones](leccion05-funciones/)** - Definición, parámetros, retorno y scope
6. **[Lección 06: Listas y Tuplas](leccion06-listas-tuplas/)** - Estructuras secuenciales y operaciones
7. **[Lección 07: Diccionarios y Conjuntos](leccion07-diccionarios-conjuntos/)** - Estructuras de mapeo y sets
8. **[Lección 08: Programación Orientada a Objetos](leccion08-programacion-orientada-objetos/)** - Clases, objetos, herencia y polimorfismo

### **Nivel Avanzado**
9. **[Lección 09: Manejo de Archivos](leccion09-manejo-archivos/)** - Lectura, escritura y gestión de archivos

11. **[Lección 11: Módulos y Paquetes](leccion11-modulos-paquetes/)** - Organización y reutilización de código
12. **[Lección 12: Proyectos Finales](leccion12-proyectos-finales/)** - Aplicaciones completas integradoras

### **Nivel Experto (Nuevo)**

## 🎯 Cómo Usar Este Curso

### Opción 1: Terminal Web Interactiva (Recomendado)
```bash
python web_interfaz/server.py
# Abre http://localhost:8000 en tu navegador
```

### Opción 2: Línea de Comandos Tradicional
1. **Sigue el orden**: Cada lección construye sobre la anterior
2. **Lee la teoría**: Cada carpeta contiene un README con explicaciones
3. **Ejecuta los ejemplos**: Prueba cada ejemplo en tu computadora
4. **Resuelve ejercicios**: Completa los ejercicios propuestos
5. **Verifica tus respuestas**: Usa el sistema de autocorrección

```bash
# Ejecutar todos los ejercicios
python ejercicios/run_tests.py

# Ejecutar ejercicios de una lección específica
python ejercicios/run_tests.py leccion01
```

## 🧪 Sistema de Ejercicios Autocorregibles

Cada lección incluye ejercicios que puedes verificar automáticamente de dos formas:

### Desde la Terminal Web
- Selecciona un ejercicio del panel lateral
- Escribe tu solución en el editor
- Haz clic en "Verificar" para obtener retroalimentación inmediata

### Desde Línea de Comandos
```bash
python ejercicios/run_tests.py              # Todos los tests
python ejercicios/run_tests.py leccion01    # Lección específica
```
