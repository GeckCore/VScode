# 🐍 Curso de Python — De cero a nivel Ingeniería Informática

Curso completo de Python en español, diseñado para aprender **programando desde el primer minuto**. Sin instalar nada: todo funciona en el navegador con Google Colab.

[![Abrir en Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/GeckCore/VScode/blob/main/leccion01-introduccion/practica.ipynb)

---

## 🎯 ¿Qué conseguirás con este curso?

Al terminar las 16 lecciones sabrás programar en Python al nivel que se exige en las asignaturas de programación de un **Grado en Ingeniería Informática**:

- Pensar como programador: descomponer problemas y resolverlos con algoritmos
- Dominar la sintaxis de Python: variables, tipos, operadores, control de flujo, funciones
- Manejar estructuras de datos (listas, diccionarios, pilas, colas, montículos) y entender su coste (Big-O)
- Programar orientado a objetos: clases, herencia, encapsulación, dataclasses
- Leer y escribir archivos, trabajar con JSON/CSV, gestionar errores con excepciones
- Organizar proyectos con módulos y paquetes, usar la librería estándar con soltura
- Conceptos avanzados: decoradores, generadores, iteradores, funciones lambda
- Introducción al análisis de datos con NumPy, pandas y matplotlib

## 🧠 Metodología: teoría + práctica inmediata

Cada lección tiene dos piezas que se usan **a la vez**:

1. **README.md** → la teoría, explicada paso a paso con ejemplos y errores típicos. Léela tranquilamente.
2. **practica.ipynb** → un notebook interactivo con ejercicios **en orden progresivo**. Cada ejercicio se corrige solo con `assert`: si tu código es correcto, verás ✅; si no, sabrás exactamente qué falla.

La regla del curso es simple: **nunca leas más de 5 minutos sin escribir código**. La teoría sin práctica se olvida.

## 🚀 Cómo usar el curso (sin instalar NADA)

1. Entra en la carpeta de la lección que toca (empieza por `leccion01-introduccion`).
2. Lee su `README.md` (la teoría).
3. Pulsa el botón azul **«Abrir en Colab»** dentro del README o abre directamente el archivo `practica.ipynb` con el enlace de Colab.
4. Haz los ejercicios en orden. Cuando todos den ✅, pasa a la siguiente lección.

> 📖 Si nunca has usado Google Colab, lee la [GUIA-COLAB.md](GUIA-COLAB.md) (2 minutos). Es gratis, solo necesitas una cuenta de Google.

## 🗺️ Ruta recomendada

- **Ritmo sugerido**: 1 lección por día (45-60 min). Las lecciones 12-16 son más largas: dales 2 días.
- **Si te atascas** en un ejercicio más de 15 minutos, mira la pista. Si aun así no sale, mira la solución, entiéndela línea a línea, ciérrala y reescríbela de memoria.
- **No copies y pegues** las soluciones: escríbelas a mano. El músculo que aprende es el que teclea.
