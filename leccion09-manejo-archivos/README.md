# Lección 09: Manejo de Archivos

## 📖 Leer y Escribir Archivos

```python
# Leer archivo
with open("archivo.txt", "r") as f:
    contenido = f.read()

# Escribir archivo
with open("archivo.txt", "w") as f:
    f.write("Hola Mundo")

# Modos: r (lectura), w (escritura), a (agregar)
```
